Library / Deal hygiene / deal-hygiene-044

Manual probability override flagged for review

Deal hygieneDealSales Hub ProfessionalIntermediate~35 min to buildFull spec

Outcome. When a rep manually sets Deal Probability (Custom) to a value that does not match deal-hygiene-011's stage-based mapping, the deal gets flagged for a manager's review, so forecast rollups do not quietly absorb an unexplained override.

When to use it, when not to

  • UseUse it once deal-hygiene-011 is live and reliably setting probability by stage, this fiche exists to catch deviations from that mapping.
  • UseUse it as a review trigger, not a block, a rep may have a legitimate reason to override probability for a specific deal, this fiche surfaces the override, it does not reverse it.
  • SkipDo not use it if reps are expected to freely adjust probability as part of normal forecasting judgment, in that case an override is the intended workflow, not an exception, and this fiche will generate constant noise.
  • SkipDo not use it without first documenting the stage-to-probability mapping the same way deal-hygiene-011 does, this fiche's detection logic depends on knowing exactly what "expected" looks like for each stage.
